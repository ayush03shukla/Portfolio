About

Research-driven engineering profile

I am a Research Associate in the Department of Electronics and Communication Engineering at IIIT Delhi. My current work focuses on radar-based foreign object debris detection for runway safety applications using millimeter-wave FMCW radar systems.

My broader research background spans radar signal processing, applied electromagnetics, EMC/EMI modeling, surrogate modeling, antennas, and RF sensing systems. I have previously worked on EMI filter insertion loss estimation using surrogate modeling techniques at IISc Bangalore and TU Graz, and on wearable antenna design at MIT Manipal.

Projects

Selected projects

Low-Rank and Sparse FOD Detection with 77 GHz mmWave Radar

Developed a radar signal processing pipeline for detecting low-RCS foreign object debris on runway-like surfaces using TI AWR1843BOOST FMCW radar data.

  • BPM-MIMO decoding and range-angle processing
  • Low-rank plus sparse decomposition using ADMM
  • OS-CFAR detection on reconstructed sparse maps
  • Application to airport runway foreign object debris detection
MATLAB FMCW ADMM OS-CFAR

Surrogate Modeling for EMI Filter Insertion Loss

Compared multiple surrogate modeling approaches for predicting EMI filter insertion loss across frequency using simulation-driven datasets.

  • Kriging, PCE, PCK, and wideband Kriging comparison
  • Model accuracy evaluation using RMSE and NRMSE
  • Workflow automation and computational efficiency improvement
  • Published at IEEE EDAPS 2023
Python UQLab Kriging EMC/EMI

Wearable WBAN Antenna Design

Designed and analyzed a wearable antenna for wireless body-area network applications using full-wave electromagnetic simulation.

  • UWB/wearable antenna design
  • Parametric and bending analysis
  • Radiation efficiency and SAR-focused optimization
  • Simulation using ANSYS HFSS
