Low-Rank and Sparse FOD Detection with 77 GHz mmWave Radar

Developed a radar signal processing framework for detecting low-RCS foreign object debris on runway-like surfaces using TI AWR1843BOOST FMCW radar data.

  • Worked on 77 GHz FMCW radar-based foreign object debris detection for airport runway safety.
  • Developed signal-processing pipelines for low-RCS target detection in ground clutter.
  • Implemented BPM-MIMO processing, range-angle processing, background subtraction, radar calibration, and detection map generation.
  • Proposed a low-rank and sparse decomposition approach solved using ADMM to separate structured ground clutter from sparse FOD targets.
  • Applied OS-CFAR detection on reconstructed sparse radar maps for final target localization.
  • Conducted RF anechoic chamber and real-world runway measurements.
  • Extending the framework toward learning-based unfolded methods for more robust radar sensing.

Tools and methods: MATLAB, FMCW radar, TI AWR1843BOOST, BPM-MIMO, range-angle processing, ADMM, low-rank and sparse decomposition, OS-CFAR.

Surrogate Modelling for EMI Filter Insertion Loss

Developed and benchmarked surrogate modelling workflows for estimating EMI filter insertion loss across frequency, with emphasis on model accuracy, training cost, resonance-heavy regions, and EMC-aware design.

  • Developed surrogate models using Kriging, Gaussian Processes, Polynomial Chaos Expansion, Polynomial Chaos Kriging, and Wideband Kriging.
  • Used uncertainty quantification and multi-objective optimization to analyze trade-offs between model accuracy and training cost.
  • Implemented Wideband Kriging in MATLAB, achieving NRMSE around 4.7% across 62 frequency samples.
  • Reduced normalized prediction error from 5.25% to 3.39% and reduced training time by 33% through algorithm enhancements.
  • Benchmarked ANSYS OptisLang DIM-GP workflows for high-fidelity modelling in resonance-heavy regions.
  • Implemented Feature Selective Validation in Python using amplitude, feature, and global difference measures across 6000-point signals.

Tools and methods: Python, MATLAB, UQLab, ANSYS OptisLang, CST Studio, Kriging, Gaussian Processes, PCE, PCK, Wideband Kriging, Feature Selective Validation.

Flexible UWB Antenna for WBAN Applications

Designed and simulated a flexible ultra-wideband antenna for wireless body area network applications using ANSYS HFSS.

  • Designed a flexible UWB antenna operating from 2.48 GHz to 11.91 GHz.
  • Achieved a peak gain of 4.84 dB at 7.75 GHz.
  • Enhanced bandwidth and radiation characteristics through parametric analysis, cuts, and ground-plane modification.
  • Validated mechanical robustness through bending simulations with negligible impact on S11 and antenna gain.

Tools and methods: ANSYS HFSS, UWB antenna design, wearable antennas, WBAN, RF simulation, bending analysis.
